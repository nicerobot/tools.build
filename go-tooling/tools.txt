# tools.txt — the canonical pinned Go tool set.
#
# One `importpath@version` per line: the SINGLE source of every quality tool's
# version. It is installed verbatim by install-tools.sh via `go install
# path@version`, into ${GOBIN} locally and into the go-tooling image in CI — so a
# developer's ~/go/bin and CI hold byte-identical tool versions, and every
# library and service builds the same way in both places.
#
# `go install path@version` builds each tool in its OWN module context (pinned by
# that tool's own go.sum + the Go checksum DB), so tools are dependency-isolated
# from each other and from this repo — there is no shared go.mod/go.sum here.
#
# Bump every tool to its latest release with `make upgrade` (scripts/go-tooling-upgrade.sh);
# verify installed binaries match this manifest with `make verify` (go-tooling/verify-tools.sh).
# Blank lines and lines beginning with `#` are ignored.
